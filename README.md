# جذور

موقع للبحث في جذور القرآن الكريم: تكرار الجذور في كل سورة وجزء، ومجموعات السور، والمواضيع، والجذور المميّزة، والخرائط والإحصاءات.

الموقع: https://adnana2014-cyber.github.io/jothoor/

## مصادر البيانات
- الصرف والجذور: [Quranic Arabic Corpus](https://corpus.quran.com) بنسخة [mustafa0x/quran-morphology](https://github.com/mustafa0x/quran-morphology)، برخصة GNU GPL.
- نص المصحف فيها من [مشروع تنزيل](https://tanzil.net).
- بيانات السور من [semarketir/quranjson](https://github.com/semarketir/quranjson)، والأجزاء من [fawazahmed0/quran-api](https://github.com/fawazahmed0/quran-api).

يحفظ الموقع مجموعات كل زائر ومواضيعه في متصفحه.
